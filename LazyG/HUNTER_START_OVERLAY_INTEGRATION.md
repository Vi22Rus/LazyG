# LazyG — Hunter BM Start/Stop and Overlay wiring (read-only, 2026-11-19)
**Status:** DEV, code integrated, CI final verification pending. User has approved the first of two stages: **connect the existing Start/Stop button and live spell-icon overlay to Hunter BM XML recommendations, without sending any key presses**. Logitech G Hub / universal input executor belongs to the second stage and is **NOT implemented**. Never label a recommendation or UI demonstration as a real cast.

## Exact current files and changes
- `LazyG/Avalonia/Engine/RotationPreviewSession.cs` — pure read-only session controller. Start accepts only the **Forever Hunter Beast Mastery PvE** embedded XML and validated per-profile settings; exposes `Running`, `Current`, `Status`. No button binding, Win32 SendInput, keyboard, Logitech calls, timing delays or synthetic cast event. `Update(GameState, at)` reruns the XML evaluator on each fresh snapshot; clears old recommendation on `Transport!=Known`, stale, wrong profile/unknown conditions and Stop. Sessions do not persist after restart.
- `LazyG/Avalonia/MainWindow.cs` — existing last-used **Start Preview / Stop Preview** button now calls `RequestStart` for supported BM PvE, and BM PvE settings page has **Start XML preview / Stop XML preview**. Uses `RotationProfileCatalog.Load("hunter","beast-mastery","PvE")` and `RotationSettingsStore.Load` from `%LOCALAPPDATA%\\LazyG\\rotations\\forever-hunter-beast-mastery-pve.json`, does not reimplement settings. Every RGB polling tick after v2/v3/Curve/LGC and optional compact decoding recomputes read-only `RotationXmlV2.Evaluate`; initial state always has **no recommendation**; missing/unknown/expired data clears it. Settings edit/reset, Setup opening, app closing and external source confirmation Stop the session.
- `LazyG/Avalonia/OverlayWindow.cs` — original overlay is preserved. When preview is active, `SetReadOnlyRecommendation` receives the **actual XML recommended SpellID**, shows its icon and name via `ForeverSpellCatalog`; higher Hunter ranks without a separate catalog image use the verified family icon while retaining the exact SpellID in caption. If no spell is recommended: clear icon and show **NO RECOMMENDATION**, not a guessed ability or the rotating NEXT demo. When Start is active, NEXT demo is disabled; labels explicitly state **LIVE XML RECOMMENDATION · READ-ONLY** and **NO INPUT**. The existing 1.5s circular GCD animation remains a **DEMO for manual NEXT only**, not a measured GCD in the real preview. No invented GCD duration.
- `LazyG/Tests/RotationFoundationTests.cs` / `RotationFoundationTests.csproj` — regression for Start/Stop, profile rejection, fresh recommendation, unknown RGB immediately clearing the spell, regained signal, expired timestamps, Stop not replaying a frame, and invalid incompatible settings.
- No Lua addon, RGB geometry, old v2/v3/Curve/LGC transport, G Hub integration, shared input executor, class-specialized keyboard code or executable spell casting modified/added. This is **not** a finished Hunter rotation.
