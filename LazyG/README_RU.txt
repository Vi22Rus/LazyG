LazyG 0.1.15-dev — пробный RGB v3 для WoW Forever (параллельно проверенному v2)

Статус: DEV, требуется игровая проверка. Последняя подтверждённая пользователем версия — 0.1.13-dev.
В 0.1.15-dev:
- Рабочая полоска RGB v2, её контрольная сумма и быстрый опрос 150 мс СОХРАНЕНЫ.
- Новый установочный пакет включает RgbV3Encoder.lua и RgbV3Panel.lua.
- Вторая полоска из 24 RGB-ячеек (4×4 UI, шаг 5) расположена под первой, y=-12 UI.
- Lua отправляет отдельные CRC16-проверяемые диагностические кадры v3 по модели Sertyrew (wire version=1).
- В тестовом пакете v3: HP игрока и цели (проценты), текущий и максимальный основной ресурс, флаги target/combat, frame counter.
- Из-за API WoW Forever HP или ресурс могут быть Unknown. Неизвестные HP передаются как 255; такие данные НЕ используются для ротаций.
- Windows захватывает одну небольшую область экрана, распознаёт обе полоски и при CRC PASS дописывает показатели v3 в Overview.
- В Windows остался изолированный декодер stepped4; текущая игровая полоска использует direct8.
- Отдельные тесты C# и Lua в GitHub Actions, проверка синтаксиса Lua.

ВАЖНО: новая версия тестовая. Если новая полоска не распознана, v2 может продолжать работать.
Новая версия не содержит XML-ротаций и не выполняет игровые действия.

КАК ПРОВЕРИТЬ:
1. Скачай EXE из последнего УСПЕШНОГО запуска GitHub Actions.
2. Запусти LazyG и через Setup установи аддон с НОВЫМ уникальным именем.
3. В меню WoW AddOns отключи ПРЕДЫДУЩИЙ тестовый LazyG-аддон, чтобы не было двух одинаковых v2 полосок.
4. Перезагрузи интерфейс (/reload) или запусти игру с новым аддоном.
5. В Setup проверь PASS для v2.
6. В Overview после чтения RGB должно появиться «RGB v3 CRC PASS · frame ... · HP ... · target HP ... · resource ...».
7. Проверь изменение HP при получении урона, HP цели и ресурса при расходе. Если показывает unknown, сообщи это — возможно, WoW Forever ограничивает соответствующий API.
8. Если v3 не распознаётся, сообщи точный текст состояния, режим окна, UI Scale; не сбрасывай настройки графики.

Важное ограничение: RGB читается только из активного и видимого окна WoW; при переходе к окну LazyG последнее измерение может оставаться на экране. Значения ещё не используются для автоматических решений.

ОТКАТ: версия 0.1.13-dev и ранее установленный Lua-аддон не изменены.

Команда PowerShell (из корня репозитория) для единого EXE:
dotnet publish LazyG/Windows/LazyG.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None
