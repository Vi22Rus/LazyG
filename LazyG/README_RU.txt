LazyG 0.1.8-dev — RGB-панель в три ряда

На основе 0.1.7-dev. Отдельный UI-прототип без ротаций и автоматического ввода.

Изменения:
- Панель 33 ячейки 3x3 логических единицы: три одинаковых ряда по 11.
- Размер панели: 51x33 логических единицы вместо прежних 135x17.
- Оставлены постоянные калибровочные маркеры (4 в начале первой строки и один в конце третьей).
- Остальные ячейки имеют тот же цвет, что и фон: декоративные разноцветные точки удалены.
- Connection Test проверяет контрольные маркеры в трёхрядной геометрии с учётом масштаба.
- Перемещение Shift+ЛКМ и остальные функции Setup сохранены.

ВАЖНО: уже установленный аддон не обновляется автоматически. Удалите старую папку своего RGB-аддона и установите новый через Setup. Сохранённая позиция панели может использоваться вновь, если SavedVariables не удалены.

Сборка единого EXE из папки Windows:
dotnet clean
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true

Проверка компиляции в Windows и тест в WoW Forever ещё не выполнены.
