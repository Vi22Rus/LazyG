LazyG 0.1.11-dev — RGB Bridge v1 (задание №1)

Windows + собственный тестовый Lua-аддон для WoW Forever.
Это development-версия. Полных ротаций и отправки клавиш здесь ещё нет.

Изменения:
- Lua: миниатюрный непрозрачный блок 4×2 ячейки (34×16 UI-единиц) в левом верхнем углу окна WoW; без перемещения, мигания, рамок и пользовательского переключателя.
- Статические контрольные маркеры и проверка целостности RGB-пакета.
- Передаются class ID, race ID, level, spec ID и очки главной ветки талантов.
- У Hunter специализация определяется существующим HunterProfile.lua, с уже протестированным пользователем C_Traits. У остальных классов spec ID на данном этапе равен 0.
- Windows: ограниченное считывание пикселей 220×120 у левого верхнего края КЛИЕНТСКОЙ области WoW; без сохранённых абсолютных координат и ручного выделения.
- При переносе/изменении размера окна новая позиция вычисляется заново.
- Обновление статуса из игры в Overview раз в 3 секунды, если WoW на переднем плане.
- Setup теперь состоит из 5 шагов; на последнем выполняется автоматическая проверка связи.
- Тест не меняет логику боёв, не отправляет клавиши и не запускает ротации.

Формат RGB Bridge v1:
4 колонки × 2 ряда, ячейка 7 UI, шаг 9 UI.
Ряд 1: green(0,255,0) | magenta(255,0,255) | white(255,255,255) | black(0,0,0)
Ряд 2: (class,race,level) | (spec,points,version=1) | checksum | magenta
checksum R=(class*17+race*11+level*7+spec*19+points*3+13)%256,
         G=255-R, B=77.
Никакого намеренного мигания: обновление только при изменении передаваемых данных.

Как проверить:
1) Скачать последнюю успешную сборку GitHub Actions.
2) Из старой установленной папки аддона удалить/переименовать прежний тестовый аддон вручную либо выбрать новое имя при установке (мастер намеренно не перезаписывает существующие папки).
3) Через Setup установить аддон с актуальной версией .toc, запустить WoW Forever и войти в игру.
4) Connection Test без выделения области должен показать класс, расу, уровень, специализацию Hunter.
5) Переместить окно WoW и повторить проверку; статус автоматически перепроверяется.

Ограничения:
- Для считывания WoW должен быть виден и находиться на переднем плане. Эксклюзивный fullscreen и чужие оверлеи могут помешать захвату.
- Автоопределение координат при смене DPI/UI Scale реализовано поиском маркеров в небольшой области. Работа на конкретных настройках монитора ещё требует проверки.
- Кросс-классовое определение специализации будет расширяться после проверки протокола.
- Установленный аддон не обновляется сам.
- GitHub Actions проверяет компиляцию EXE и базовый старт; теста WoW/RGB в CI нет.

Сборка единого EXE (из Windows):
dotnet clean
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
