LazyG 0.1.7-dev — компактная RGB-панель

На основе 0.1.6-dev. Отдельный UI-прототип, без ротаций и автоматического ввода.

Изменения:
- Панель 32 цветовых ячейки 3x3 логических единицы в одном ряду, с однородным фоном и перетаскиванием Shift+ЛКМ.
- Маркеры: зелёный, пурпурный, белый, чёрный в начале и пурпурный в конце. Остальные цвета статические — тестовый шаблон.
- Connection Test сканирует выделенную область, допускает поля по краям и проверяет маркер на другом конце.
- Выбор области и тест сворачивают модальное окно Setup вместо Hide() во избежание обрыва модального диалога.

ВАЖНО: уже установленный аддон не обновляется автоматически. Удалите старую папку собственного RGB-аддона и установите его заново через Setup.

Проверки: структурная проверка исходников и архива. Компиляция на Windows и проверка в WoW Forever не проводились.

Сборка единого EXE из папки Windows:
dotnet clean
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
