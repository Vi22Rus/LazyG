LazyG 0.1.18-dev — Curve HP/Resource с шагом 5% (WoW Forever)

Результат теста 0.1.17-dev: пользователь подтвердил работу Blizzard Curve: при полном здоровье диапазон 90–100%, при HP цели около 50% — диапазон 50–59%, при HP цели около 20% — 20–29%. Передача RGB v2 и CRC v3 продолжает работать.

В этой DEV-сборке:
- Третья Curve-полоска расширена с 32 до 62 RGB-ячеек: 2 маркера, по 1 статусу и 19 порогам для HP игрока, HP цели, ресурса.
- Пороговые диапазоны 0–4%, 5–9%, ... 90–94%, 95–100%.
- Windows-считывание увеличено до 350px ширины; прежние v2 и CRC v3 не изменены.
- Это диагностические диапазоны, а не точные проценты или готовые условия XML-ротаций.

Тест:
1. Скачай exe из раздела Artifacts → LazyG-Windows-x64 у указанного GitHub Actions run после успешного завершения.
2. Через Setup установи новый аддон под новым именем; выключи предыдущие тестовые LazyG-аддоны в WoW и выполни /reload.
3. Проверь v2 и CRC PASS v3; Curve при полном HP/ресурсе должен показывать 95–100%, не 90–100%.
4. Снизь HP цели примерно до 50%, 20% и проверь, что диапазон обновляется с шагом 5%.
5. При ошибке пришли строку RGB Connection и игровой HP/ресурс; не сбрасывай настройки графики.

CI-компиляция и тест WoW — отдельные этапы. Точка отката — 0.1.17-dev.

PowerShell для одного EXE:
dotnet publish LazyG/Windows/LazyG.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None
